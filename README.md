# Shree Tiles Contractor — Black & Gold Design

Updated visual palette for the Olive Studio layout: black/charcoal backgrounds with gold accents.

## Included files
- `index.html`
- `about.html`
- `services.html`
- `projects.html` — responsive gallery with category filters
- `contact.html` — form validation and pre-filled WhatsApp enquiry
- `assets/css/style.css`
- `assets/js/main.js`
- `assets/images/` — add local project photos here

## Run
Extract the ZIP, open the folder in VS Code, then open `index.html` with Live Server. Internet is needed for Bootstrap CDN, Bootstrap Icons and remote illustrative images.

## Before publishing
1. In `assets/js/main.js`, replace `91XXXXXXXXXX` with the actual WhatsApp number including country code (digits only).
2. Replace placeholder phone/contact details.
3. Replace illustrative stock images with genuine project photos.
4. Test all pages, filters and the form on mobile and desktop.

Static front-end only. The form opens WhatsApp with a pre-filled message; the visitor must send it manually. No database or form storage is included.
